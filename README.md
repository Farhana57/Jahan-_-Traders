# Jahan Traders - Jute Products Web Application

A full-stack web application built for **Jahan Traders** to showcase and manage eco-friendly jute products, featuring a modern React frontend and a robust backend.

## 🌟 Features
- Responsive and modern UI with Tailwind CSS.
- Detailed product pages with high-resolution local images and key features.
- Contact and quote submission system.
- Full-stack integration with frontend and backend structure.

## 🛠️ Tech Stack
- **Frontend:** React, React Router, Tailwind CSS, Lucide Icons, Vite
- **Backend:** Node.js, Express.js
- **Version Control:** Git & GitHub
